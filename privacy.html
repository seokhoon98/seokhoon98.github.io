런코 개인정보 처리방침

시행일: 2026년 11월 23일 · 운영자: 런코(Runco) 운영자 · 문의: tjr532@gmail.com

런코(이하 "앱")의 운영자는 개인정보 보호법에 따라 이용자의 개인정보를 다음과 같이 처리합니다.

1. 기본 원칙

런코는 운영자가 관리하는 서버가 없습니다. 아래 정보는 이용자의 폰과 워치 안에만 저장되며, 운영자는 이 정보를 받거나 볼 수 없습니다. 이용자가 AI 기능을 쓸 때만 해당 내용이 이용자의 키로 AI 서비스(Google 등)에 직접 전송됩니다(4번).

2. 처리하는 정보와 목적

  • 내 정보(나이, 성별, 러닝 경력, 목표, 운동 가능 요일·강도, 통증 부위, 직접 입력한 달리기 기록): 맞춤 조언과 훈련 계획
  • 삼성 헬스 운동 기록(운동 종류, 시간, 거리, 칼로리, 속도, 케이던스, 고도, 운동 위치(GPS 경로), 운동 중 심박수): 기록 보기·분석, 러닝 능력 계산, 코스 저장
  • 삼성 헬스 심박수(최근 7일): 안정시 심박을 계산해 개인 심박 구간을 정하는 데만 사용(계산한 값만 기기에 저장)
  • 현재 위치(코스 탭을 열거나 코스 추천을 누를 때): 주변 코스 검색
  • AI 질문·답변 기록, 저장한 코스, 훈련 계획: 기록 보기
  • 앱 오류 기록(기기 모델, 안드로이드 버전, 오류 내용): 다음 실행 때 화면에 보여 주기(외부로 보내지 않음)
  • 워치 알림 설정: 폰과 워치 사이 설정 맞추기

3. 삼성 헬스 데이터

  • 런코는 Samsung Health의 운동(Exercise), 운동 위치(Exercise location), 심박수(Heart rate) 데이터를 읽기만 하며, 삼성 헬스에 쓰거나 바꾸지 않습니다.
  • 삼성 헬스 데이터는 2번 목적에만 쓰며, 광고·마케팅에 쓰거나 판매·제3자에게 제공하지 않습니다. 이용자가 AI 기능을 쓸 때 요약이 AI 서비스로 전송되는 경우(4번)는 예외로, 이용자의 별도 동의가 있을 때만 이루어집니다.
  • 권한은 삼성 헬스 → 설정에서 언제든 끌 수 있습니다.

4. 개인정보의 국외 이전 (AI 기능 사용 시, 선택 동의)

  • Google LLC(미국) — Gemini API: 질문, 최근 30일 운동 기록 요약(심박 포함), 내 정보, 선택한 운동의 상세 기록, 러닝 능력 값. 목적: AI 답변·총평·계획·코스 추천 생성.
  • Tavily(미국) — 웹 검색: AI가 만든 검색어(Tavily 키를 넣은 경우만). 목적: 답변 근거 자료 검색.
  • 이전 시기·방법: AI 기능을 쓸 때마다 암호화된 통신(HTTPS)으로 전송.
  • 보유 기간: 각 회사의 정책에 따름. 무료 Gemini 키를 쓰면 입력 내용이 Google의 서비스 개선에 쓰이고 사람이 검토할 수 있습니다.
  • 동의하지 않아도 AI 기능을 제외한 나머지 기능은 쓸 수 있습니다.

5. 그 밖의 외부 전송 (코스 추천·지도)

  • 코스 데이터: 코스 탭을 열거나 코스 추천을 누르면, 현재 위치가 속한 약 10km 칸의 코스 데이터 파일을 GitHub(GitHub Pages, 미국)에서 받습니다. 이때 GitHub에는 칸 번호와 기기의 IP 주소가 전달됩니다. 이 파일을 받지 못하면 현재 위치 좌표로 OpenStreetMap 검색 서버(Overpass)에 직접 검색합니다.
  • 동네 이름: 현재 위치 좌표를 안드로이드 위치 변환 서비스(Google)나 OpenStreetMap Nominatim으로 보내 동네 이름을 확인합니다.
  • 지도 표시: 지도를 볼 때 Google 지도(또는 OpenStreetMap 지도 서버)에 지도 영역 요청이 전송됩니다.
  • 이 과정에서 삼성 헬스 데이터는 전송되지 않습니다.

6. 보관 기간과 파기

기기 안의 정보는 이용자가 앱에서 지우거나 앱을 삭제할 때까지 보관되며, 앱을 삭제하면 모두 지워집니다. AI 질문 기록, 코스, 내 정보는 앱 안에서 각각 지울 수 있습니다.

7. 이용자의 권리

이용자는 앱 안에서 언제든 정보를 보고, 고치고, 지울 수 있습니다. 선택 동의(위치, AI 국외 이전)는 앱의 내 정보 → 앱 설정 → 약관 및 동의에서 철회할 수 있습니다.

8. 안전성 확보 조치

AI 서비스 키는 안드로이드 암호화 저장소에 저장합니다. 외부 전송은 모두 암호화된 통신으로 합니다.

9. 만 18세 미만

런코는 만 18세 미만은 이용할 수 없으며, 그 개인정보를 처리하지 않습니다.

Runco Privacy Policy (English summary)

Effective: November 23, 2026 · Operator: Runco operator · Contact: tjr532@gmail.com

  • No developer server. All data stays on the user's phone and watch. The developer never receives it.
  • Samsung Health data (read-only): Exercise, Exercise location and Heart rate are read to show and analyze the user's workouts, estimate running fitness (VDOT) and save running routes. Heart rate from the last 7 days is used only to estimate resting heart rate for personal heart-rate zones; only the calculated value is stored. Runco never writes to Samsung Health, never uses this data for advertising, and never sells or shares it with third parties. Permissions can be revoked in Samsung Health settings at any time.
  • AI features (optional, separate consent): when the user asks the AI coach, the question, a summary of the last 30 days of workouts, the user's profile and fitness values are sent over HTTPS to Google Gemini API (USA) using the user's own API key, and search queries to Tavily (USA) if configured. AI features are disabled without consent.
  • Location: current location is used only for course recommendations (when the user opens the Courses tab or asks for a recommendation). The app downloads the course-data file for the ~10 km grid cell from GitHub Pages (USA), which receives the cell number and the device IP address; if that fails, coordinates are sent to OpenStreetMap search servers. Coordinates are also sent to Android geocoding or OpenStreetMap Nominatim to get the area name. No Samsung Health data is sent in this process.
  • Retention and deletion: data is kept on the device until the user deletes it in the app or uninstalls the app.
  • Age: the app is for users aged 18 and over.
